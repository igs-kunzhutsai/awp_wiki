# conventions/ — 寫 code 的規範

**該怎麼寫。** 命名規則、code style、目錄結構、新增模組的 checklist。

| | |
|---|---|
| **放** | 命名慣例、格式規則、檔案組織方式、既有 codebase 的已知不一致 |
| **不放** | 為什麼選這個規範（→ `decisions/`）、怎麼串接（→ `flow/`） |

## 界線

`conventions/` 回答「照這樣寫」，`decisions/` 回答「為什麼是這樣」。
同一件事若兩邊都要寫，規範放這裡、理由放 `decisions/`，兩邊互相連結，**不要重複內容**。

> 本檔只說明「這個目錄放什麼」，不列出頁面清單（`WIKI-SPEC.md` §2）。
