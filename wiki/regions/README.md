# regions/ — 跨專案的地區規則

**各地區的功能需求與法規差異對照表。**

| | |
|---|---|
| **放** | 跨專案通用的地區差異：各地區功能開關、法規要求、認證需求 |
| **不放** | 單一專案的地區設定值（→ `projects/<專案>/setup.md` 的表格） |

## 界線

- **同一條地區規則適用所有專案** → 放這裡
- **只有這個遊戲在這個地區的設定值** → 放 `projects/<專案>/`

## 寫成表格，不要寫成一地區一頁

```markdown
| 需求 | 菲律賓 | 澳門 | 美國 |
|---|---|---|---|
| 需 X 認證 | 是 | 否 | 是 |
| JP 上限限制 | 有 | 無 | 有 |
```

一眼並排比較，新增地區是**加一欄**不是加一頁。

> 本檔只說明「這個目錄放什麼」，不列出頁面清單（`WIKI-SPEC.md` §2）。
